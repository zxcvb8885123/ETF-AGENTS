# 公司事件與整體市場情緒

第三位分析師的 2.2 報告涵蓋兩個獨立範圍：對整體台股只產生一次 `market_sentiment`，對交易池內每家公司逐檔產生事件判讀。公司新聞、個股行情與市場成交背景不能代替全市場情緒；資料不足時，各範圍各自標示無法判斷。

## 目前已接入

- 每日批次、輸出契約與 Validator 使用 2.2。程式依相同 Snapshot 和 `decision_cutoff` 重建市場情緒欄位，檢查公司事件的引用與一致性，模型不能覆寫重建結果。
- 全市場 RSS 收集與版本化 `market_news_input` 接線已實作；新聞標註須覆蓋視窗內全部項目，並依 canonical content ID 去重。歷史原頁的可得時間按實際取得時間記錄，不回填至過去。
- `cli/market_context_probe.py` 可補抓交易所的成交、指數及法人買賣資料，作為交易背景與來源查核，不參與正式情緒計算。
- 每日決策鏈把重大公司事件的事實與脈絡直接交給股票層級多空研究；獨立事件研究與舊 2.1、2.0 封存仍按各自原始契約驗證。

## 正式資料限制

目前全市場新聞來源的比賽使用授權尚未確認，正式市場情緒因此輸出 `unavailable`／`unknown`，不能解讀為中性。公司維度的 `MarketPerceptionResult`、搜尋摘要及市場成交數字也不能補成全市場情緒。只有授權核准、來源與時間可追溯、涵蓋範圍完整的資料才能進入正式計算。
