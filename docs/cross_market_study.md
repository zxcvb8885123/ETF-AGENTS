# 跨市場隔夜訊號回測

## 這是什麼

這是一份**離線研究**，用來回答：[隔夜市場背景](overnight_market.md)的訊號（美股、日韓、VIX、台指期夜盤、方向一致性），過去兩年對台股隔日有沒有預測力？答案用來決定「要不要把它變成確定性的現金姿態下限」。

它不屬於每日決策鏈：`decision/`、`automation/` 與 `scripts/run_daily_pipeline.py` 都不匯入它（有測試鎖定），也不回寫任何決策產物。

## 怎麼做

- 程式：`src/etf_agent/research/cross_market_study/`；指令 `cli/cross_market_study.py`。
- 訊號：重用正式流程的歷史訊號函式（視窗與公式與每日背景相同），決策時點固定台北 07:00。
- 資料：Yahoo 日線（美股、代理、日韓、VIX，目標為加權指數 OHLC）與 FinMind 台指期盤後列，約兩年（760 個日曆日，才夠最低 250 個交易日）。原始資料不可變地存在 `artifacts/cross_market_study/data/`，結果在 `studies/`。

```bash
set -a; . ./.env; set +a          # 需要 FINMIND_TOKEN
.venv/bin/python cli/cross_market_study.py fetch      # 抓並保存歷史
.venv/bin/python cli/cross_market_study.py fetch-pool --decision-input <decision_input.json>   # 凍結交易池日線與官方均價
.venv/bin/python cli/cross_market_study.py analyze    # 重建並統計（有交易池資料時一併做現金姿態模擬）
```

## 事先登記的判準（看結果前寫死）

- 樣本少於 250 個交易日，只報筆數，不判通過。
- 正式檢定只有三組：美股主訊號、夜盤漲跌幅、方向一致性分數，對「開盤跳空」（當日開盤 ÷ 前日收盤）的等級相關（Rank IC）。三組採 Bonferroni 近似，|t| ≥ 2.4 且前後兩半樣本符號一致才算通過。
- 其他目標（開到收、收到收、均價代理、振幅）與其他訊號只作探索，**不判通過**（避免多重檢定）。
- 事後補的目標（第一輪結果出來後才加，報告標「事後」）：成交日價到收盤、成交日均價到隔日均價。以當日均價代理成交，看成交後的報酬，這才是現金姿態的決策價值所在；但因為是看過結果才加，可信度低於事先登記者。

## 第一輪結果（2024-10-01～2026-10-30，約 500 個交易日）

事實：

- 隔夜訊號與同日開盤跳空高度相關。Rank IC：夜盤 0.75（t 25）、美股主訊號 0.63（t 18）、一致性分數 0.57（t 16），前後兩半同號，三組都通過。跳空方向命中率：夜盤 82%、美股 77%、一致性 78%（Wilson 95% 下界皆高於 73%）。
- 訊號為負面的日子（69 天）平均跳空 −0.68%、收到收 −1.43%；正面（141 天）平均跳空 +0.63%、收到收 +1.08%。一致向下（54 天）跳空 −0.41%，一致向上（105 天）+0.51%。
- 事後補的目標：訊號對「當日均價到隔日均價」的預測力弱得多。夜盤 IC 0.17（t 3.9，前半 0.09、後半 0.22，通過但前半很弱）；美股主訊號 0.08（t 1.7）與一致性 0.06（t 1.4）都未通過。

推論：

- 隔夜訊號幾乎完全被開盤價吸收；而比賽以當日成交均價成交，所以它解釋「今天的價位」，對「買進之後賺不賺」只有夜盤有一點點、且不穩的額外資訊。拿它直接調高現金（少買），這份結果無法證明有利。

限制：

1. 目標用加權指數與 (開+高+低+收)/4 的均價代理，不是比賽用的官方成交均價，也不是交易池；正式結論要用校準報告的官方均價重跑。
2. 夜盤採 FinMind 歷史（日期語意為當日日盤之前的那段夜盤）。
3. 第一輪沒有扣交易成本，也沒有模擬現金姿態對淨值的影響。
4. 成交日價到收盤的 IC（0.19～0.28）受均價代理含收盤價影響，可能有機械性偏誤，不當證據。

## 結論

目前證據只支持「隔夜訊號是開盤跳空的好指標」，**不支持**把它做成確定性的姿態下限。維持現狀（只給風險 Agent 當背景）是合理的。
