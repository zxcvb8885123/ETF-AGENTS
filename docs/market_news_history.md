# 市場新聞缺日補抓

## 這是什麼

RSS 只保留最近幾天的新聞。若某幾天漏抓，可以依明確日期，從公開目錄補抓當天的新聞原頁，補進同一個資料包。

- 只收指定來源與目錄，不是「全部新聞」；報告也不能使用「全部新聞」的說法。
- 原頁只用標題與摘要，不當全文。
- 標籤、門檻與接入規則同[全市場新聞收集與接入](market_news_integration.md)。

## 收集範圍

| 媒體 | 目錄 | 原頁網址形式 |
| --- | --- | --- |
| 中央社 | 台股標籤頁、證券列表 | `/news/<類別>/<12 位數字>.aspx` |
| 自由時報 | 站內搜尋，關鍵字「台股」、依日期排序 | `ec.ltn.com.tw` 的 `/article/breakingnews|paper/<編號>` |

實際範圍會寫進查詢紀錄。

## 收集規則

| 項目 | 規則 |
| --- | --- |
| 日期 | 起日不得晚於迄日、不得是未來、區間不超過 31 日 |
| 連線 | 只連白名單公開主機，僅 HTTPS，轉向到其他主機即失敗 |
| 查詢 | 自由時報只允許關鍵字「台股」、依日期排序，加日期與頁碼 |
| 分頁 | 跟隨實際的下一頁，最多 20 頁；重複連結視為循環並拒絕 |
| 大小 | 單一回應上限 2,000,000 位元組 |
| 保存 | 目錄、原始回應，以及分頁是否走完 |
| 失敗 | 網路失敗不宣稱完成，也不補零、不補假新聞 |

## 資料包 1.1

| 規則 | 說明 |
| --- | --- |
| 輸入 | 同時接收 RSS 與歷史原頁 |
| 原頁必要欄位 | 帶時區的發布時間、實際取得時間、標題、原始內容雜湊 |
| 媒體數 | 以媒體計；同一媒體的 RSS 與原頁不重複增加來源數 |
| 缺口說明 | 不再固定寫「RSS 不涵蓋全部歷史」，改寫實際收集範圍 |
| 舊版 | 1.0 維持原樣重建，封存內容不改寫 |

## 時間規則

- 「可得時間」是實際取得時間。今天補抓的原頁不能回填成過去就已可得。
- 取得日的頁面可能已被更新，不能拿目前版本去加入取得日之前的正式回測。
- 真正的歷史回測需要「當時的內容版本」與「可得時間」證據；只改發布時間不行。

## 怎麼用

```bash
.venv/bin/python cli/market_news.py backfill \
  --start-date 2026-10-01 --end-date 2026-10-03 \
  --database var/etf_agent.db \
  --output-root artifacts/market_news_history
```

- `--database` 選配；有提供時，補抓結果會追加存入抓取表，不覆寫既有版本。
- 補抓後依[接入文件](market_news_integration.md)做標籤、判讀與接入。
- 這是人工補救用，每日排程不會呼叫。

實測參考（2026-10-05）：補入 10/1～10/4 共 92 篇原頁，加上 60 則 RSS，輸入 152 項、去重後 151 則。

## 授權

- 中央社與自由時報的 RSS 條款允許個人與非營利組織的非商業用途並須標示來源，提供標題、前言與連結，不是全文轉載授權；條款沒有逐一點名 AI CUP，是否屬非商業取決於實際使用方式。
- 2026-10-23 起四個來源由使用者核准（歷史原頁屬使用者自行判斷），見[稽核紀錄](source_audit/2026-10-23_market_news_sources.md)。核准只對之後的截止時間生效。
- 不得以 RSS 條款宣稱取得全部原頁、全文或其他用途的授權。

來源規範：[中央社 RSS](https://www.cna.com.tw/about/rss.aspx)、[自由時報 RSS](https://service.ltn.com.tw/RSS)
