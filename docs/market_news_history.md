## 使用規範查核結果

[中央社 RSS](https://www.cna.com.tw/about/rss.aspx) 明確允許個人、非營利組織的非商業用途，須註明來源；提供的是標題、前言與連結，並非全文轉載授權。[自由時報 RSS](https://service.ltn.com.tw/RSS) 也允許個人／非營利的非商業 RSS 使用，須註明來源。原始規範頁、取得時間與雜湊保存於本次 `terms_review.json`。

規範沒有逐名指定 AI CUP 是否適用，也不能因未列名就斷言所有比賽都被禁止。是否落在非商業範圍，需看參賽與成果的實際使用方式。這是用途與使用權問題，不是資料取得缺口。

本次本地新聞收集與研究測試已完成，不因這個用途註記停止抓資料或判讀。正式比賽資料包仍維持既有 approved 規則，不以 RSS 的有限使用條款宣稱取得全部原頁、全文或其他用途授權。報告將本地研究看法與正式比賽通道狀態分開，不能把診斷結果改寫成已核准正式結果。

## 可重複執行

```bash
.venv/bin/python cli/market_news.py backfill \
  --start-date 2026-10-01 --end-date 2026-10-03 \
  --database var/etf_agent.db \
  --output-root artifacts/market_news_history
```

核心收集器在 `perception/market_news/history.py`，限制公開主機、原頁路徑、日期視窗、分頁及回應大小。跟隨實際下一頁，會將中文網址編碼；分頁改動日期或來源即拒絕。保存目錄、原始回應及分頁是否走完。網路失敗不宣稱完成，也不補零或假新聞。

資料包 1.1 接收 RSS 與歷史原頁；原頁內容由 metadata 重建，必須有帶時區的 published_at、實際 available_at、標題與原始內容雜湊。新增來源種類不增加媒體數。舊 1.0 成對輸入保持原版本的重建結果，封存內容不改寫；新的 1.1 不再固定加入「RSS 不涵蓋全部歷史」缺口，而是描述實際收集範圍。

今天取得的原頁可能已更新。其 available_at 保留今天，不能冒充過去已存入系統，也不能用當前版本加入取得日前的正式回測。真正歷史回測需要當時的內容版本及可得時間證據，不能只把 published_at 改成當年的日期。
