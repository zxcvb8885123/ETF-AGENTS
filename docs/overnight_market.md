# 隔夜市場背景

## 這是什麼

台股前一天收盤之後，美股、日韓與台指期夜盤已經開過一輪。這份「隔夜背景」把這段時間的表現整理成一小段摘要，只給兩個地方當參考：

- 風險 Agent 決定「現金姿態」（積極、中性、保守）時。
- 最終報告裡的「隔夜市場背景」一行。

它**不是**市場情緒，不併入全市場情緒；不給分析師、多空研究員或交易 Agent；不產生候選、權重或訂單；也不預測今天台股指數的方向。

## 資料有哪些

| 類別 | 標的 | 來源 |
| --- | --- | --- |
| 美股三大指數 | 標普 500、那斯達克、費城半導體 | Yahoo Finance 日線（經 yfinance） |
| 台股在美國的代理 | EWT（台灣 ETF）、TSM（台積電 ADR） | 同上 |
| 日韓指數 | 日經 225、KOSPI | 同上 |
| 美股波動率 | VIX | 同上 |
| 台指期夜盤 | 臺指期月合約 | 期交所官網即時行情 |

兩個來源都已由使用者核准（Yahoo：2026-10-30；期交所官網夜盤：2026-10-30 在被告知實際端點不是 OpenAPI 後核准），核准設定在 `config/overnight_market_sources.json`。

- 核准是使用者的決定，不是來源方的同意。
- 若 Yahoo 改回未核准，整體結果固定「不可用、方向未知」，逐標的數字只在診斷輸出可見，不進現金姿態簡報。
- 若只有夜盤未核准或抓不到，只有夜盤降級。核准時間晚於決策截止的來源視同未核准。

## 一天怎麼跑

1. 抓取：`./start.sh daily` 在恐懼貪婪抓取之後、決策截止之前執行 `cli/overnight_market.py capture`，原始回應不可變地存在 `artifacts/data/overnight_market/`。任一來源沒抓全會等 20 秒重抓，最多 3 次；仍失敗只降級，不中止每日流程。另有每天台北 05:05 的獨立排程（`scripts/launchd/com.etf-agents.overnight-capture.plist.template`），夜盤 05:00 結束後再抓一次，供 07:00 的決策使用。
2. 組成資料包：建決策輸入時，選出「全部資料都在截止前取得」的最後一次抓取，連同來源核准與台股最近交易日，由程式算出結果。
3. 使用：只有風險 Agent 的現金姿態與最終報告讀它。
4. 驗證：輸入驗證用原始回應重算。數字被改、雜湊不符、網址或主機不在白名單、抓取晚於截止、缺時區，都拒絕。

## 哪個時間的 run 能用什麼（台北時間）

| 資料 | 完成時間 | 能用的 run |
| --- | --- | --- |
| 台股現貨 | 13:30 | 20:00 抓完資料後的 21:00、隔日 07:00 |
| 日經、KOSPI | 約 14:30 | 21:00 與 07:00 |
| 美股指數、EWT、TSM | 美東 16:00＝台北 04:00（夏令，到 11/1）或 05:00（冬令，11/2 起） | 只有 07:00 |
| VIX | 美東 16:15（台北 04:15／05:15） | 只有 07:00 |
| 台指期夜盤 | 05:00 結束 | 只有 07:00（08:45 日盤開盤前） |

**21:00 是備援 run**：美股還沒開、夜盤還在進行，所以隔夜背景整體「不可用」是預期結果，不需要處理。每日排程：週一至週五 07:00、週日至週四 21:00。

## 怎麼計算

### 時間窗

- 可用視窗：台股最近交易日 13:30 之後，到決策截止之前，已經「完成」的時段。
- 美股每日線的完成時間是當日美東 16:00（夏令／冬令自動換算，提早收盤日仍取 16:00，偏保守）。完成時間晚於抓取時間的日線一律丟棄，不用盤中價。
- 視窗內有多個時段（例如連假、週一納入週五收盤）就累乘。
- 視窗內沒有完成時段時，該標的與整體「不可用」。

### 每個標的算三個數字

最新時段漲跌幅、視窗內累計漲跌幅，以及最新單日報酬在歷史單日報酬中的百分位（歷史不足時留空，不硬算）。新的抓取回看約 420 個日曆日、百分位看近 250 個單日報酬（約一年）；舊封存仍看近 20 個。台指期夜盤目前只有當次報價，**沒有一年歷史百分位**（需要合法的歷史來源，尚未接入）。

### 整體判讀

- 主訊號 = 費半與標普 500 累計漲跌幅的平均，兩者都可用才有結果。小於等於 −1.5% 為負面，大於等於 +1.0% 為正面，其間為中性。
- 台股代理（EWT、TSM 可用者平均）與主訊號方向相反、且兩者幅度都超過 0.75%，判為「分歧」。
- 那斯達克或代理單項失敗，只降級並記錄缺口。
- 引用編號只給已核准且可用的標的；只有現金姿態可引用，個股層級的主張引用一律拒絕。
- 固定附三條限制：代理不是因果、只代表隔夜一段、不預測指數方向。

### 方向一致性

把美股三指數、EWT、TSM、日韓指數、夜盤（VIX 不算）的漲跌幅，以 ±0.30% 為持平帶分成上、下、持平。至少 3 個訊號、同向比例達 75% 且沒有反向者，標為「一致向上」或「一致向下」；不足 3 個為「資訊不足」；其餘為「分歧」。這只描述同向程度，不是預測。

新增的日韓、VIX、夜盤目前只增加背景與一致性，**不影響整體判讀的規則**；要不要讓它們影響姿態下限，必須先用離線研究驗證（見[跨市場隔夜訊號回測](cross_market_study.md)，結論是目前證據不支持）。

## 台指期夜盤的特別規則

- 來源是期交所官網即時行情，只保存商品代號、日期、時間、最後價、參考價、成交量；挑成交量最大的月合約，漲跌幅 = 最後價 ÷ 前一日日盤結算價 − 1。
- 為什麼不用期交所 OpenAPI 或 FinMind：兩者的「盤後」列是「同一日日盤之前」那段夜盤，要等當日日盤收盤後才出現，07:00 的 run 只拿得到前一天的夜盤，不能當決策輸入。它們只適合事後校準（2026-10-30 以探測與實測確認）。
- 完成條件（不符一律「不可用」）：抓取時間在夜盤結束（報價日當天台北 05:00）之後、報價時間不晚於 05:05 且不晚於抓取時間，夜盤結束時間落在台股最近交易日 13:30 與決策截止之間。平日 21:00 的 run 因夜盤進行中，夜盤一律不可用，不影響整體。
- 已知限制：夜盤端點的日期與時間格式只有少量實抓樣本和測試資料驗證；最後一筆成交在午夜前（到 05:00 都沒有新成交）會被保守判為「尚未結束」。找不到夜盤或費半對台股隔日開盤預測力的公開量化統計，所以只當背景。

## 限制

- Yahoo 資料經 yfinance 取得，沒有服務保證。
- 盤前、美股期貨、匯率沒有納入。
- 代理與指數只是相關背景，不是台股因果。

## 版本與相容

- 舊封存的 1.0（美股與代理，夜盤欄位為空）、1.1（加日韓、VIX、夜盤）維持原樣重建，百分位仍看 20 日；新的決策輸入建立 1.2。
- 沒有任何抓取時，決策輸入不附隔夜欄位，既有 fixture 與舊 run 重建不變。
- 隔夜背景不改變決策輸入的團隊資料版本。
