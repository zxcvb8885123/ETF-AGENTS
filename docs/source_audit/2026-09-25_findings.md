狀態：**交易狀態來源仍為 candidate，正式決策維持 blocked**。本次 blocked 不由外部 ETF 權重缺漏造成；目前取得的 D-Plan 指南未將 Active Share 列為每日硬性上限。本次延續 [9/24 初探](2026-09-24_findings.md)，在 9/25 重新取得相同十個 TWSE／TPEx 公開端點。每份原始 JSON 及抓取時的 HTTP 標頭、時間與 SHA-256 保存於本機 `artifacts/source-audit/2026-09-25/`；可追溯的[來源清單](2026-09-25_manifest.json)、[固定 12 檔樣本](2026-09-25_sample.json)及[就緒判定](2026-09-25_readiness.json)另存於此目錄。未更改 `config/data_sources.json` 的正式核准清單，也未建立 `TradabilityAssessment`。

## 休市日與跨日結果

[TWSE 115 年開休市表](https://www.twse.com.tw/holidaySchedule/holidaySchedule?response=html)列出 2026-09-25 中秋節、9/28 教師節休市；[TPEx 公告](https://www.tpex.org.tw/storage/eb_data/11509/11503027221.html)也明列櫃買市場這兩天休市。因此 9/25 午間抓到多數 9/24 狀態不能判作更新逾期，更不能當作 9/25 交易許可。兩市場完整、可版本化的逐日交易日曆仍未接入。

十個端點均回 HTTP 200 且可解析 JSON。相對 9/24 原始回應，九個端點的內容雜湊不變；TWSE 處置端點由 7 列變 8 列，雜湊改變。這證明端點可能改版或滾動資料，**不能**由列數推斷只有一筆新增；需逐筆保存版本和生效區間。TPEx 注意名單 38 列混有民國 115/09/23（18 列）和 09/24（20 列）；TPEx 處置 23 列亦含多個公告日期。查詢結果不能直接作單日完整現況。

TWSE 注意端點仍回一列 `Code`、`Date` 為空的佔位資料；TPEx 當日停復牌端點仍回一列證券代號及事件欄位皆空的資料。空白列不是「所有股票皆可交易」的證據。固定 12 檔中，`3374`、`4979` 出現在 TPEx 注意及處置，`6488` 出現在注意，`3491` 出現在歷史停復牌；其餘樣本未命中候選資料列。12 檔一律保持 `unknown`，命中還需查有效時段，未命中還需來源完整性證據。

## 使用與保存條件

[TPEx OpenAPI 規格](https://www.tpex.org.tw/openapi/)歡迎介接，且列有此次狀態端點；但[TPEx 網站使用條款](https://www.tpex.org.tw/zh-tw/gtsm_disclaimer.html)對未經同意方式的自動化下載設限。[TWSE 使用條款](https://wwwc.twse.com.tw/zh/terms/use.html)同樣對自動化下載與資料重製設限，另提及政府資料開放平臺授權例外。**推論：**OpenAPI 的介接說明和一般網站條款如何共同適用於持續自動擷取、原始回應保存及競賽使用，目前未能從公開文字確定；故本次僅作有限來源稽核，不核准正式 Provider 或安排持續抓取。後續須釐清可用方式與保存範圍，並保存其授權證據。

已找到更明確的**候選授權路徑**：政府資料開放平臺將 [TWSE 開休市日期](https://data.gov.tw/dataset/11761)、[TPEx 變更／分盤／管理／停止交易](https://data.gov.tw/dataset/11736)、[TPEx 注意](https://data.gov.tw/dataset/11395)、[TPEx 處置](https://data.gov.tw/dataset/11396)及[TPEx 歷史停復牌](https://data.gov.tw/dataset/48665)列為「政府資料開放授權條款－第 1 版」。[授權條款](https://data.gov.tw/license)准許利用和重製，但要求標示原資料提供機關。這只證明**所列政府開放資料集**有授權聲明；尚須把每個資料集的下載資源與目前 OpenAPI JSON 逐一對應、核對版本與取得方式，不能概括授權全部十個端點，也不能用授權替代資料完整性驗證。

已對其中兩份資料做[有限 CSV／JSON 對照](2026-09-25_ogd_crosscheck.json)，原始 CSV 保存在本機稽核 artifact。TPEx 變更／分盤／管理資料兩種格式都是 21 列，代號重數一致。**TPEx 注意資料的政府開放 CSV 是 9/24 的 20 列，OpenAPI JSON 卻是 9/23 與 9/24 合計 38 列**；JSON 先按 `Date=1150924` 篩選後，代號重數才與 CSV 一致。這只是代號與日期的小樣本核對，未證明全部欄位、發布完成時點或直接 JSON 端點的授權等價。正式 Collector 必須保留各列日期，不可把 JSON 全部列當成同一日。
