# 融資水位訊號：現況說明

## 這是什麼

台股恐懼貪婪指標原本只看融資 5 日變化率，融資慢慢爬到很高、但每天變化不大時看不出來。現在加了第四項「融資水位」：目前的融資水位，在自己近一年的歷史中排第幾名。指標整體說明見[台股恐懼貪婪指標](market_fear_greed.md)。

## 做法

- 不直接用融資餘額，因為它會隨市值長期上升，今年的「高」可能只是五年前的「普通」。
- 改用「融資金額 ÷ 加權指數」，加權指數代表市值，能抵銷市場變大的影響；再取近 250 個交易日的百分位，越高越貪婪。
- 融資金額沿用已核准的 FinMind 資料；加權指數用證交所的月檔資料，經使用者於 2026-11-04 核准（限比賽研究、非商業），已寫入來源核准設定。
- 來源核對與不採用的來源見[融資水位來源核對](source_audit/2026-11-04_margin_level_sources.md)。證交所網站條款頁查不到，條款風險由使用者承擔，與 VIX 相同。

## 規則

- 需要融資金額與加權指數至少 250 個共同交易日；不足、過期或缺任一原始回應，該項不可用並寫入資料缺口，不補值。
- 兩個來源都已核准才計入正式分數。
- 回填完成時間晚於決策截止時間的決策，看不到這些資料；今天補抓的歷史不回填成過去可得。
- 同日數值不一致，整份拒絕。
- 計分版本：有加權指數、不含 Put/Call 的新抓取為 v3（VIX、融資 5 日變化率、融資水位三項）；仍帶 Put/Call 的舊抓取維持 v2，沒有加權指數的維持 v1，舊封存逐位元重建。2026-11-04 起新抓取不再抓 Put/Call，因為政府資料只有約 20 個交易日，會因差一天而不可用，且已有融資水位。
- 融資水位只是情緒輸入，由風險 Agent 當證據之一，不直接變成減碼或加碼規則。

## 已知限制

- 融資水位是慢訊號，多頭市場可以高很久，單獨看會太早減碼。
- 250 日百分位只代表近一年的相對位置。
- 加權指數不含新上市與增資，長期有偏差，一年窗口內影響小。
- 融資維持率在 FinMind 需付費、證交所網站條款禁止自動化擷取，所以不採用。
- 項目數改變後分數分布會變，區間門檻（25／45／55／75）可能需要重新檢視；目前沒有這項檢視。
