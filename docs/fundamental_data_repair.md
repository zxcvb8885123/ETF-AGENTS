# 基本面缺口補抓

分工：

- 基本面分析師負責解讀。
- Data Agent 負責抓取、口徑核對與版本保存。

互動研究可使用 `.venv/bin/python cli/fundamental_repair.py`，環境須已有 `FINMIND_TOKEN`。CLI 不會自動讀取或輸出憑證，也不跑後續的交易 Agent。

## 目前完成的範圍

### 一般業：去年同期補抓

- 以 TWSE 一般業的「當期累計損益表」作基準。
- 以 FinMind 的去年與當年單季損益作補充。
- 程式用 Decimal 合計 Q1 至指定季度。
- 當年的營收、營業利益、稅後淨利，必須與官方累計金額**完全相符**，才會納入去年同期合計。
- EPS 不加總。

遇到以下情況一律拒絕：

- 缺季
- 欄位重複
- 股票誤配
- 非有限值
- 金額或截止時間衝突

保留原始回應與官方基準，並標記 vendor 來源。

### 金融業：欄位對應（2026-10-03）

- fh／basi／bd／ins 的「本期稅後淨利（淨損）」與「本期淨利（淨損）」，對應 `net_income`。
- 「淨收益」另存為 `net_revenue`，**不能當作 `revenue`**。
- 兩個淨利欄位若同時存在、數值卻不相等，拒絕該列並保存解析警告。
- 不以繼續營業單位或母公司業主淨利，冒充整體淨利。

官方映射版本升為 `twse-tpex-openapi-2026-10-v2`。更新需重新收集並另建快照，不改舊版本。

分析摘要的 `financial_facts` 提供金融業當期稅後淨利／淨收益原值與來源證據。本次不接入未確認的金融業跨年公式。

**一個容易誤會的地方**：前面說「金融業專屬報表未接入」，指的是 FinMind 去年同期補抓入口仍只支援一般業。這不代表官方 Data Agent 不支援金融業當期欄位。

## 尚未完成或有限制

- **去年的報表範圍與重編資訊尚未取得**，所以 `reporting_scope=unknown`。當期相符，只能驗證當期金額口徑，不能保證去年沒有重編。報告必須保留這個限制。
- 這個入口尚未接入：金融業專屬報表、TPEx 補抓、資產負債表歷史補抓、同業比較標準。不得用一般業公式硬補。
- 沒有合法可比的同業資料時，仍須明列「缺少業別比較標準」。
- 公司產業代碼已接入分析摘要並附引用證據，但沒有名稱對應或同業基準。
- Yahoo Finance 已實際抓取兩檔季度損益，TWSE 公司基本資料已實抓產業代碼。Yahoo 尚未接入正式基本面指標。
- FinMind 可補歷史財報，但不等於來源已提供完整的財報上下文。

## 時間點規則

- FinMind 的 `available_at` 使用本次抓取時間，來源發布時間保留 `null`。
- FinMind 財報與新公司基本資料文件的 `published_at`，只是觀測時間的相容欄位，不能宣稱是公司發布時間。
- 每次補抓都另建 ResearchSnapshot 與不可變 manifest。
- `--decision-cutoff` 可指定歷史時鐘。但今天取得的資料不會進入過去的快照，不能靠改 cutoff 偽裝歷史回測。

## 使用流程

- 每日排程**目前不會**自動呼叫這個補抓入口。
- 互動研究的順序：補抓一次 → 重建指標 → 再分析。
- 失敗時交回確切的資料缺口，不無限重試。憑證或額度失敗就停止本輪。
- 新快照採研究模式，不構成正式每日決策輸入，也不是 D-Plan。

## 對外報告用語

### 先分清楚缺口的原因

分析摘要缺欄位，不等於來源沒有資料。先確認：原始回應、欄位映射、摘要傳遞。

| 狀態 | 可以怎麼說 |
| --- | --- |
| 已取得但未接入 | 欄位存在，尚未接入 |
| 口徑未確認 | 口徑尚未確認 |
| 尚未取得 | 尚未取得 |
| 來源實際失敗 | 有抓取失敗紀錄時才說 |
| 狀態未確認 | 狀態未確認 |

- 沒有抓取失敗紀錄時，不得寫「抓不到」。
- 只有金融業原始表的稅後淨利欄位確實存在、且數值有限時，才說明「欄位尚未接入」。不因欄位存在，就補算未確認的年增率。

### `data_gap_explanations`

基本面摘要另有 `data_gap_explanations`。程式依實際快照，說明缺少的期間、報表與欄位，並區分三種情況：

1. 缺整張損益表
2. 已有表，但缺欄位
3. 基期非正數，無法算一般年增率

內部錯誤碼保留在 `unavailable_metrics`，不抄入對外報告。不能把「分析輸入缺資料」寫成「公司未公告」。

### 分類與寫法

- 對外分類用「正面／中性／負面」。內部契約仍是 `positive`／`neutral`／`negative`／`unknown`。
- 沒有可用資料時仍為 `unknown`。對外暫列「中性」時，必須另寫「資料不足，暫不判斷」，不得冒充已完成的中性分析。
- 中文表達參考 [ASD-STE100 官方原則](https://www.asd-ste100.org/STE_faq.html)：短句、用詞一致。不宣稱符合英文詞彙規範。
- 每檔的順序：先判斷 → 再列理由與反證 → 最後列具體缺口。
- 數值與證據仍可由原始 JSON 重建。
