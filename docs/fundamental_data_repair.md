# 基本面缺口補抓

基本面分析師負責解讀；Data Agent 負責抓取、口徑核對、版本保存。互動研究可使用 `.venv/bin/python cli/fundamental_repair.py`，環境須已有 `FINMIND_TOKEN`。CLI 不自動讀取或輸出憑證，不跑後續交易 Agent。

目前完成：TWSE 一般業當期累計損益表作基準，FinMind 去年及當年單季損益作補充。程式以 Decimal 合計 Q1 至指定季度，當年營收、營業利益、稅後淨利必須全部與官方累計金額完全相符，才納入去年同期合計。EPS 不加總。缺季、欄位重複、股票誤配、非有限值、金額或截止時間衝突均拒絕；保留原始回應及官方基準，標記 vendor 來源。

去年公司報表範圍及重編資訊尚未取得，`reporting_scope=unknown`，當期相符只能驗證當期金額口徑，不能保證去年沒有重編。報告必須保留此限制。金融業專屬報表、TPEx 補抓、資產負債表歷史補抓及同業比較標準尚未接入這個入口；不得用一般業公式硬補。

2026-10-03 金融業欄位對應已接入：fh／basi／bd／ins 的「本期稅後淨利（淨損）」與「本期淨利（淨損）」對應 net_income；「淨收益」另存 net_revenue，不能當作 revenue。兩個淨利欄位若同時存在且不等值，拒絕該列並保存解析警告。不以繼續營業單位或母公司業主淨利冒充整體淨利。

官方映射版本升為 twse-tpex-openapi-2026-10-v2。更新需重新收集並另建快照，不改舊版本。分析摘要的 financial_facts 提供金融業當期稅後淨利／淨收益原值及來源證據；本次不接入未確認的金融業跨年公式。前述「金融業專屬報表未接入這個入口」指 FinMind 去年同期補抓入口仍只支援一般業，不代表官方 Data Agent 不支援金融業當期欄位。

FinMind 的 `available_at` 使用本次抓取時間，來源發布時間保留 null。FinMind 財報及新公司基本資料文件的 `published_at` 僅作觀測時間相容欄位，不能宣稱公司發布時間。每次另建 ResearchSnapshot 與不可變 manifest。`--decision-cutoff` 可指定歷史時鐘；今天取得的資料不會進入過去快照，不能靠更改 cutoff 偽裝歷史回測。

Yahoo Finance 已實際抓取兩檔季度損益，TWSE 公司基本資料已實抓產業代碼；公司產業代碼已接入分析摘要並提供引用證據，未提供名稱對應或同業基準；Yahoo 尚未接入正式基本面指標。沒有合法可比同業資料時，仍須明列缺少業別比較標準。FinMind 可補的歷史財報不等於來源已提供完整財報上下文。

每日排程目前不會自動呼叫此補抓入口。互動研究依序補抓一次、重建指標、再分析；失敗交回確切資料缺口，不無限重試。來源憑證或額度失敗停止本輪。新快照採研究模式，不構成正式每日決策輸入或 D-Plan。

## 對外報告用語

分析摘要缺欄位不等於來源沒有資料。先確認原始回應、欄位映射及摘要傳遞，區分已取得但未接入、口徑未確認、尚未取得、來源實際失敗及狀態未確認。沒有抓取失敗紀錄時，不得寫「抓不到」。只有金融業原始表的稅後淨利欄位確實存在且數值有限時，才說明欄位尚未接入；不因欄位存在而直接補算未確認的年增率。

基本面摘要另提供 `data_gap_explanations`。程式依實際快照說明缺少的期間、報表及欄位，區分「缺整張損益表」、「已有表但缺欄位」與「基期非正數，無法算一般年增率」。內部錯誤碼保留在 `unavailable_metrics`，不抄入對外報告。不能將分析輸入缺資料寫成公司未公告。

對外分類使用正面／中性／負面。內部契約仍保留 positive／neutral／negative／unknown。沒有可用資料時仍為 unknown；對外暫列中性時必須另寫「資料不足，暫不判斷」，不得冒充已完成的中性分析。
