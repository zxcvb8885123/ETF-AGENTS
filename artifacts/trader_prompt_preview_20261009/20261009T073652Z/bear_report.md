# 空頭研究｜新版指令兩檔試跑

實際執行日期：2026-10-09。資料截止：2026-10-05 16:48（台北時間）。沿用已驗證封存分析；本報告是研究論點，不是今日決策或訂單。

### 台達電（2308.TW）

**論點強度：弱。**

技術面分析師指出目前屬下跌後的回升階段：六十日均線才剛停止下滑並回升，尚未形成長時間持續上揚，五月高點仍未收復。這是已觀察到的事實，但只代表上升趨勢的持久性尚待確認，不代表趨勢已轉弱；價格目前仍在二十日與六十日均線上方。另有七月十日成交量為零，量能支持度無法用該日驗證。

高重大性事件為子公司決議發行海外交換債，並有泰國廠房重建工程公告。事件分析師認為籌資與工程投入本身尚未證明新增訂單、產能利用率或獲利改善，且缺少交換後持股影響及同幣別、同合併範圍的支出比較。因此這是待確認的不確定性，不是已發生的惡化；公司也澄清媒體成長預估來自法人而非公司，不能當成公司承諾。

基本面雖為正面，但去年同期財報由資料商補抓，合併範圍與是否重編尚未確認；缺少產業名稱對照與同業比較，最新月營收只到八月，且單月較七月下降。這些缺口降低了成長與獲利改善結論的可靠度，不能推論為營運惡化。

**需要重新評估的情況：**

- 若後續封存走勢顯示六十日均線持續上揚並收復五月高點，需重新評估趨勢持久性的疑慮。
- 若去年同期報表確認為相同合併範圍且未重編，並取得更新的月營收，需重新評估基本面可靠度的疑慮。
- 若出現新增訂單、泰國廠房效益或交換債資金運用的可驗證結果，需重新評估事件不確定性。

### 富邦金（2881.TW）

**論點強度：弱。**

技術面中期趨勢仍為上升，但九月中旬以來價格在高檔小幅整理，近期漲勢較前段放緩。分析師明確表示未見上升結構被破壞，所以這只是漲勢放緩的疑慮，不是轉弱事實。

基本面為中性，八月營收年減但累計營收年增，方向不一致。上半年損益缺少去年同期可比資料，無法確認獲利是否持續改善；金融業專用指標與同業基準尚未接入，最新月營收只到八月。這使得正面投資假設無法被支持，但現有資料不足以認定獲利惡化。

公司事件多屬資金與業務安排：資產基礎證券、私募基金認購與授信資產處分，公告未提供足夠的未來收益、信用風險與流動性資料，處分公告也未列處分利益。事件分析師認為無法確認集團獲利影響，屬待確認的不確定性；中等重大性事件未顯示已發生的負面結果。

**需要重新評估的情況：**

- 若後續封存走勢顯示價格突破高檔整理並延續上升，需重新評估漲勢放緩的疑慮。
- 若取得二〇二五年上半年同口徑損益表與更新月營收，顯示獲利持續成長，需重新評估基本面無法確認的疑慮。
- 若投資標的的收益、信用風險與流動性資料被補齊且未見不利，需重新評估事件不確定性。
