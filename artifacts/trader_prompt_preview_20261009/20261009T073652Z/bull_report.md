# 多頭研究｜新版指令兩檔試跑

實際執行日期：2026-10-09。資料截止：2026-10-05 16:48（台北時間）。沿用已驗證封存分析；本報告是研究論點，不是今日決策或訂單。

### 台達電（2308.TW）

**論點強度：中。**

依據：已接入的上半年資料顯示營收與稅後淨利較去年同期成長，營業利益率也提高；八月營收與累計營收年增。推論：成長同時伴隨獲利能力改善，是支持持有的主要營運理由。限制：去年同期財報由資料商補抓，合併範圍與是否重編尚未確認；缺少同業比較，不能判定優於同業；最新月營收只到八月，九月之後的延續性無法確認；八月單月較七月下降。

依據：價格維持在二十日與六十日均線上方，近期回檔低點高於七月底低點，二十日均線重新上升，六十日均線剛停止下滑並回升。推論：技術面支持目前的回升結構，與基本面方向一致。限制：目前屬下跌後的回升階段，五月高點尚未收復，六十日均線尚未形成長時間上揚，不能視為整個半年的上升趨勢；七月十日成交量為零，量能未被用作證據。

**需要重新評估的情況：**

- 若後續同口徑月營收或財報顯示營收、獲利或營業利益率的改善未能延續，需重新評估營運支持理由。
- 若去年同期財報確認為不同合併範圍或經重編，使年增與利益率改善的比較不成立，需重新評估。
- 若後續走勢顯示回檔低點被跌破、價格失守均線，回升結構被破壞，需重新評估技術面支持理由。

### 富邦金（2881.TW）

**論點強度：弱。**

依據：價格中期呈上升結構，六十日均線持續上升、二十日均線向上，最新價格仍在兩條均線上方，尚未見中期結構被破壞。推論：技術面提供零星但實際的支持持有理由。限制：九月中旬以來在高檔小幅整理、漲勢放緩，不能把整理解讀為下一段上漲已開始；七月十日成交量為零，未用作量能證據；此論點只涉及價格結構，不代表營運改善。

依據：累計營收年增（雖八月單月年減），且資產負債表已接入；基本面分析師指出金融業不能套用一般製造業標準，現有負債比例不單獨作為負面證據。推論：目前沒有確認的基本面惡化，累計營收年增是間接的正面跡象。限制：缺少去年同期損益表，無法計算獲利年增；金融業營收不等於獲利；缺少金融業專用指標與同業基準；公司事件分析師判斷為中性，八月自結損益、投資與授信資產處分公告均不足以確認集團獲利改善，故不將這些事件作為利多。

**需要重新評估的情況：**

- 若後續走勢顯示中期上升結構被破壞（失守均線、前段整理低點被跌破），需重新評估技術面支持理由。
- 若補齊同口徑去年同期損益後，顯示稅後淨利或金融業淨收益年減，需重新評估基本面的間接支持。
